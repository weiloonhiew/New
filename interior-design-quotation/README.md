# Interior Design Quotation Toolkit

An Excel workbook to speed up quotation preparation: a reusable **price
catalog** plus a **quotation template** that pulls from it automatically,
laid out to match the contracts you already send clients.

## Files

- `Interior_Design_Quotation_Toolkit.xlsx` — the workbook. Open it in
  Excel or WPS Office.

## What's inside

1. **Read Me** — full instructions (also summarized below).
2. **Price Catalog** — ~80 starter line items across 17 work categories
   (Professional Services, Preliminaries, Hacking, Plumbing, Masonry,
   Waterproofing, Plasterceiling, Plastering, Painting, Glass, Aluminium &
   Steel, Carpentry, Worktop, Electrical, Flooring, Aircon, Miscellaneous).
   Costs are median values pulled from 8 of your own past contracts, with
   the 25% selling markup you've used consistently across them. Edit
   costs/markup any time — selling price recalculates automatically.
3. **Quotation Template** — branded like your existing contracts (company
   header, client/site details, numbered sections, subtotals, discount,
   9% GST, grand total, payment terms, T&Cs). Pick items from a
   category-filtered dropdown, enter quantity, and the line amount,
   section subtotal and grand total all calculate themselves.

## Quick start for a new project

1. Duplicate the **Quotation Template** sheet (right-click the tab →
   *Move or Copy* → check *Create a copy*) so the master template stays
   blank for next time.
2. Fill in client and site details at the top.
3. Under each section, click a Description cell and choose from the
   dropdown, or type a custom item if it's not in the catalog yet.
4. Enter quantities. Amounts, subtotals, discount, GST and the grand
   total update live.
5. Adjust Discount % / GST Rate if needed.
6. `File → Save As → PDF` (or print to PDF) for the client-ready document.

Consider adding any custom item you typed back into the **Price
Catalog** sheet so it's ready to reuse on the next quotation.
